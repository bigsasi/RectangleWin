RectangleWin

Version 1.2.0 • Windows 11 Modernized Edition

A lightweight, keyboard-driven window management and snapping utility for Windows 10 & 11, inspired by macOS Rectangle and Spectacle.

• 23 Snap Actions: Halves, corner quadrants, vertical thirds, maximize, center, and step resizes.
• Multi-Monitor Ready: Quickly move windows across displays preserving relative coordinates.
• Modern Native Architecture: Per-Monitor V2 DPI awareness, Windows Dark & Light themes, and single-instance enforcement.
• Zero External Runtimes: Built entirely in pure Go with native Windows Win32 APIs.
